Python 版本管理（替代 pyenv）

```bash
uv python install 3.11          # 下载安装指定Python版本（无需系统预装）
uv python list                  # 列出本机已经下载的Python
uv python pin 3.11              # 项目锁定Python版本，生成 .python‑version
```

项目工程命令（pyproject.toml + uv.lock，Agent 项目最核心

```bash
uv init --no-package            # 初始化业务应用项目（非开源库）
uv add fastapi pydantic         # 添加生产依赖，自动更新 pyproject.toml + uv.lock
uv add --dev pytest ruff        # 添加开发依赖（测试、格式化工具）
uv remove fastapi               # 删除依赖

uv lock                         # 只做依赖解析，更新 uv.lock，**不安装**
uv sync                         # 根据 uv.lock 同步 .venv 虚拟环境
uv sync --no-dev                # 生产环境：不安装开发依赖
uv sync --frozen                # CI严格模式：lock文件不许改动，改动直接报错

uv tree                         # 打印完整依赖树，排查版本冲突
uv audit                        # 扫描依赖安全漏洞
uv export --format requirements-txt  # 导出为传统 requirements.txt，兼容老脚本
```
