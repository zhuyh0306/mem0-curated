## 这套计划怎么用

原文自己定的规则，照做即可：

1. **精读 / 扫读分离**：精读打开指定小节，边读边写 3 条笔记，读完必须能复述；扫读只判断「这个东西在我项目里归哪个模块」，不写笔记。
2. **时间按当天累计偏移**：`00:24` 是开始后第 24 分钟，`02:00` 是当天结束。
3. **每天都由三段组成**：读（输入）→ 做（产出可演示的结果）→ 收（归档、写 3 行 notes、对照验收物打勾）。
4. **止损 15 分钟**：卡住超过 15 分钟就换实现或查资料，不硬耗。
5. **验收物必须真实存在**：每天的 `📦 今日验收物` 要能在仓库里找到、能当场跑出来；做不完就登记成「已知限制」，不留隐形欠账。

笔记落到 `notes/day-XX.md`，格式见 [notes/README.md](notes/README.md)。
